# So unterstützt KI das Gespräch

Bei einer gesprochenen Nachricht arbeiten mehrere Schritte zusammen:

**Sprache → erkannter Text → Übersetzung → Nachricht für die andere Seite**

Eine verfügbare Sprachausgabe liest die Übersetzung zusätzlich vor. KasselDIALOG nutzt dafür lokal betriebene KI-Modelle. Die Modelle unterstützen das Gespräch; sie prüfen weder den Sachverhalt noch treffen sie fachliche Entscheidungen.
