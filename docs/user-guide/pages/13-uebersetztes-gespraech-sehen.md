# Übersetztes Gespräch sehen

In Ihrem Verlauf sehen Sie Ihre eigenen Nachrichten als erkannten oder eingegebenen Text. Nachrichten des Gastes erscheinen für Sie übersetzt. Auf der Gästeansicht ist es umgekehrt.

Die Anzeige hilft beim Nachvollziehen des Gesprächs. Sie beweist nicht, dass eine Übersetzung inhaltlich richtig ist. Bestätigen Sie wichtige Aussagen mit dem Gegenüber.
