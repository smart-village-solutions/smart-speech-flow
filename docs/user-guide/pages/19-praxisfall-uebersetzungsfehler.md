# Praxisfall Übersetzungsfehler

**Übung mit erfundenem Gespräch:** Der Gast zeigt auf einem mitgebrachten Zettel einen Termin am **13.** des Monats. In der angezeigten Übersetzung seiner gesprochenen Nachricht steht **30.**

Sie sollen den Termin weitergeben. **Was tun Sie, bevor Sie fortfahren?**

Denken Sie an die ursprüngliche Aussage, die Möglichkeit zur Texteingabe und die Bestätigung durch den Gast. Die Auflösung folgt auf der nächsten Folie.
