# Gespräch eröffnen

Wählen Sie in der Gesprächsübersicht „Neues Gespräch starten“. KasselDIALOG erzeugt eine Sitzung und zeigt die Einladung an.

Falls bereits ein eigenes Gespräch läuft, weist KasselDIALOG darauf hin, dass ein neues Gespräch dieses beendet. Prüfen Sie den Hinweis, bevor Sie „Trotzdem starten“ wählen. Ein eigenes offenes Gespräch können Sie über die Übersicht wieder aufrufen.
