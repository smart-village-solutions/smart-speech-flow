# Unklarheiten klären

Bei Namen, Zahlen, Daten und wichtigen Aussagen: **nachfragen und bestätigen lassen**.

1. Wiederholen Sie die Aussage langsam und in einem kürzeren Satz.
2. Wechseln Sie bei Bedarf zur Texteingabe und prüfen Sie die Schreibweise.
3. Lassen Sie sich die gemeinte Bedeutung vom Gast bestätigen.

Bleibt die Verständigung unklar, folgen Sie dem Vorgehen Ihrer Abteilung. Treffen Sie keine rechtlich erhebliche Entscheidung allein auf Grundlage einer ungeprüften Übersetzung.
