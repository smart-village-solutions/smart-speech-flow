# Einladung weitergeben und warten

1. Geben Sie Code, Link oder QR-Code nur an die eingeladene Person weiter.
2. Der Gast wählt seine Sprache und sieht die Informationen zum Gespräch. Nur wenn die einsetzende Organisation die optionale Speicherung aktiviert hat, erscheint zusätzlich eine freiwillige Speicherfrage. Der Gast kann sie ablehnen und „Loslegen“ wählen.
3. Warten Sie auf den Beitritt. KasselDIALOG öffnet Ihre Gesprächsansicht dann automatisch. Über „Zum Gespräch wechseln“ können Sie sie auch vorher öffnen.
