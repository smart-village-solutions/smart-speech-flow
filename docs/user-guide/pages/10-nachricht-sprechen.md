# Nachricht sprechen

Wählen Sie das Mikrofonsymbol „Aufnehmen“ und sprechen Sie. Erlauben Sie den Mikrofonzugriff im Browser, falls Sie danach gefragt werden. Nach spätestens 20 Sekunden endet die Aufnahme automatisch; mit einem erneuten Tippen können Sie sie früher senden.

**Wichtig:** Die Spracheingabe für eine einzelne Nachricht ist nicht gleichbedeutend mit der optionalen Speicherung des gesamten Gesprächs für Tests oder Qualitätssicherung.
