# Hilfe und Dokumentstand

Bei Problemen unterstützt Sie **[Corinna Neige](mailto:Corinna.Neige@kassel.de)**. Beobachtungen zur Nutzung senden Sie über „Feedback“ in KasselDIALOG.

Diese Anleitung beschreibt die heutige KasselDIALOG-Installation für gesprächsführende Mitarbeitende. Ihre Organisation legt fest, welche Gesprächsarten für Ihre Abteilung freigegeben sind.

**Redaktionsstand:** 3. Oktober 2026. Die konkrete Produktversion wird vor der Veröffentlichung ergänzt.

**Ausblick:** Eine gezielte Aufzeichnung einzelner Gesprächsabschnitte ist geplant; sie gehört noch nicht zum aktuellen Bedienablauf.
