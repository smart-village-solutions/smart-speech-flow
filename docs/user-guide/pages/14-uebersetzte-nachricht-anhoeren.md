# Übersetzte Nachricht anhören

Wenn zu einer eingehenden Nachricht eine Sprachausgabe bereitsteht, wird sie bei ihrem Eintreffen automatisch abgespielt. Über „Pausieren“ halten Sie sie an; mit „Abspielen“ hören Sie sie erneut. Lesen Sie den angezeigten Text mit.

Klingt eine Aussage unklar, fragen Sie nach. Die Sprachausgabe ist eine zusätzliche Hilfe für die Verständigung.
