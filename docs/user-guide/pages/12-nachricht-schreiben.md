# Nachricht schreiben

Wählen Sie das Tastatursymbol „Tastatur öffnen“, geben Sie Ihre Nachricht ein und wählen Sie das Sendesymbol „Text senden“. Eine Texteingabe hilft, wenn das Mikrofon nicht gut versteht oder eine Schreibweise wichtig ist.

Formulieren Sie kurz und eindeutig. Prüfen Sie auch bei geschriebenen Nachrichten, ob der Gast die Bedeutung richtig verstanden hat.
