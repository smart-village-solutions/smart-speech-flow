# Grenzen der KI erkennen

Eine flüssige Übersetzung kann trotzdem falsch sein. Besonders anfällig sind Namen, Zahlen, Fachwörter, Dialekte und Sprache bei Hintergrundlärm. Schon ein Fehler bei einem Datum oder Betrag kann die Bedeutung verändern.

**Ihre Aufgabe:** Wichtige Angaben prüfen, Unklarheiten mit dem Gast klären und fachliche Entscheidungen selbst beziehungsweise über den vorgesehenen Prüfweg treffen.
