# Gespräch beenden

Ist der Austausch abgeschlossen, wählen Sie „Gespräch beenden“ und bestätigen Sie den Hinweis. Die Sitzung wird für beide Gesprächsseiten beendet.

Halten Sie danach kurz fest, was gut lief und wo es Probleme gab: Über „Feedback“ erreichen Sie das Formular für Ihre Rückmeldung.
