# KasselDIALOG auf einen Blick

Zwei Menschen sprechen oder schreiben in unterschiedlichen Sprachen. KasselDIALOG überträgt ihre Nachrichten und unterstützt so die Verständigung. Fachliche Entscheidungen treffen weiterhin Menschen.

**Wir sind in einer frühen Rolloutphase.** Zur Geschwindigkeit und Stabilität unter realen Einsatzbedingungen liegen noch keine Erfahrungen vor. Bitte teilen Sie uns Ihre Beobachtungen über „Feedback“ mit.
