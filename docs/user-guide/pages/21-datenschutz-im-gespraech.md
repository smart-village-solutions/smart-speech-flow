# Datenschutz vor und im Gespräch

Vor der Nutzung müssen Mitarbeitende und Gäste die **gültige Datenschutzinformation für KasselDIALOG** erhalten können. Nutzen Sie dafür den von Ihrer Organisation bereitgestellten Weg.

Nach der Sprachauswahl erhält der Gast Informationen zum Gespräch. Nur wenn die Organisation die optionale Speicherung aktiviert hat, erscheint eine freiwillige Speicherfrage. Der Gast kann ablehnen und das reguläre Gespräch mit „Loslegen“ beginnen.

Schützen Sie Einladungslinks und vermeiden Sie unnötige personenbezogene Angaben.
