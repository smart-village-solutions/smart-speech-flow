# Probleme lösen

| Problem | Nächster Schritt |
| --- | --- |
| Gast kann nicht beitreten | Einladung und Verbindung prüfen; Zugang erneut öffnen. |
| Mikrofon reagiert nicht | Mikrofonfreigabe im Browser und Gerät prüfen; erneut versuchen oder schreiben. |
| Nachricht kommt nicht an | Verbindung prüfen; bei angebotenem „Erneut senden“ nochmals senden. |

Hält eine **technische Störung** an, brechen Sie das Gespräch mit KasselDIALOG ab. Melden Sie den Vorfall über „Feedback“ und wenden Sie sich bei Problemen an [Corinna Neige](mailto:Corinna.Neige@kassel.de). Schreiben Sie keine Gesprächsinhalte in den Freitext.
