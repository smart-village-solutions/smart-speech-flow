# Einladung anzeigen

Für das neue Gespräch sehen Sie einen Sitzungscode, einen Beitrittslink und einen QR-Code. Der Gast kann über einen dieser Wege ohne eigenes Konto beitreten.

Nutzen Sie „Link kopieren“, wenn Sie die Einladung digital weitergeben. Mit „Abbrechen“ schließen Sie die Einladung; KasselDIALOG veranlasst dann das Beenden der neu erstellten Sitzung.
