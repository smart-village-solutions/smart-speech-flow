# Einladung erhalten und Passwort festlegen

Für Ihren ersten Zugang erhalten Sie eine E-Mail mit dem Betreff „Willkommen bei KasselDIALOG!“:

1. Öffnen Sie „Passwort festlegen“ innerhalb der in der E-Mail genannten Gültigkeitsdauer.
2. Erscheint die Zwischenseite „Passwort aktualisieren“, wählen Sie „Klicken Sie hier um fortzufahren“.
3. Geben Sie ein neues Passwort ein, bestätigen Sie es und wählen Sie „Absenden“.

Wenn Sie keine Einladung erwartet haben oder der Link abgelaufen ist, wenden Sie sich an Corinna Neige.
